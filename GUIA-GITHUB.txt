COMO PUBLICAR O DIA A DIA DA ELO — versão 4.3.26

O pacote está preparado para o workflow já existente no repositório. A publicação não foi feita nesta conversa porque não há sessão autenticada do GitHub.

Para publicar manualmente:
1. Entre no repositório oficial: https://github.com/tonlm10/dia-a-dia-da-elo-app
2. Use “Add file” → “Upload files” e selecione `app-upload.zip` na raiz.
3. Confirme a alteração com “Commit changes”.
4. Acompanhe a execução do GitHub Actions. Confirme a publicação somente após o workflow terminar sem erros.

Se o workflow não iniciar, revise a configuração do GitHub Actions e as permissões do repositório antes de tentar novamente. Teste o site publicado em um aparelho real antes de divulgar a atualização.
