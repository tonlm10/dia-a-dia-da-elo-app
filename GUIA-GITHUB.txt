ATUALIZAÇÃO AUTOMÁTICA — V4.2.0

1. Baixe app-upload.zip (ou descompacte diretamente no repositório).
2. Se o seu repositório usa o workflow automático do GitHub Actions:
   - Envie o arquivo com o nome exato: app-upload.zip para a RAIZ do repositório.
   - Faça o commit direto na branch main.
   - Aguarde o workflow "Importar ZIP do app" concluir.
   - O ZIP é descompactado e removido automaticamente, publicando os arquivos da nova versão v4.2.0.
3. Se preferir atualizar manualmente:
   - Descompacte o conteúdo deste ZIP diretamente na raiz do seu repositório local e faça o push.
